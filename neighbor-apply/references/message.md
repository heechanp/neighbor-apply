# 서로이웃 신청 메시지 쓰는 법

목표: 받는 사람이 "내 글 읽고 보냈구나" 하고 느끼게. 매크로처럼 보이는 건 **틀이 같고, 글 내용이 없고, 칭찬만 큰** 메시지다.

## 기본 뼈대 (순서는 섞어 쓴다)

1. **부르기**: 닉네임 + 님 (아래 '닉네임 다루기')
2. **그 글에서 한 가지 짚기**: 제목만 보지 말고 본문에서 눈에 띈 것 하나(그 사람이 겪은 일, 정리 방식, 결론, 사진 속 장면). 숫자·사양을 그대로 옮기지 않는다.
3. **나 한 줄**: settings.md의 계정 소개 중 하나. 글 주제와 이어지면 이어서("저도 금리 공부 중이라"), 안 이어지면 짧게.
4. **신청 한마디**: 매번 다르게.

- 길이: **40~90자**, 문장 2~3개. 길면 오히려 매크로 같다.
- 존댓말, 편한 블로그 말투(~요). "~습니다"체는 10개 중 1~2개만.
- 줄바꿈은 넣지 않는다(한 덩어리).

## 닉네임 다루기

- 닉네임 뒤에 **님**. 이미 '님'으로 끝나면 그대로.
- 이모지·특수문자(♡, ★, _, ~)와 괄호 속 말은 뺀다. 예: `하루♡맘(육아)` → `하루맘님`.
- 너무 길면(8자 넘음) 앞쪽 뜻 있는 부분만, 그래도 어색하면 블로그 이름으로 부르거나 이름 없이 쓴다.
- 영어 ID 같은 닉네임(`abc1234`)은 이름 없이 쓴다.
- 닉네임을 **매번 첫마디에 두지 않는다**. 앞(부르기)·가운데(글 얘기 뒤)·없음을 섞는다.

## 첫마디 유형 (한 번 실행에서 골고루 섞는다)

- A. 닉네임 먼저: "리모콘대장님, 11월 경제동향 정리 읽다가…"
- B. 글 내용 먼저: "수출은 좋은데 장바구니 물가는 그대로라는 얘기에 공감했어요."
- C. 내 상황 먼저: "저도 요즘 경제지표 읽는 연습 중인데…"
- D. 짧은 반응 먼저: "아, 이 정리 딱 필요했어요."
- E. 질문 섞기(가볍게, 답 안 해도 되는): "다음 달 동향도 정리하시나요?"

## 예시 (지솜, 경제 계정)

- 리모콘대장님, 11월 경제동향을 수출·소비·고용으로 나눠 보니 훨씬 잘 읽혔어요. 저도 경제 공부 기록 중이라 서로이웃 신청드려요!
- 수출은 좋은데 물가 체감은 그대로라는 부분 저도 똑같이 느꼈어요. 경제 뉴스 정리하는 지솜이에요, 앞으로 자주 들를게요 :)
- 뉴히어로님 2027년 전망 글 보고 왔어요. 연구기관별로 모아 주신 게 좋아서 서이추 남겨요~
- 아이랑 통큰 경제동화 읽은 후기 재밌게 봤어요. 경제 공부하는 지솜인데 이웃하면 좋겠어요!

## 쓰지 않는 것

- 판에 박힌 말: "좋은 글 잘 봤습니다", "소통해요", "맞팔해요", "함께 성장해요", "블로그 너무 예뻐요", "우리 서로이웃해요~"(네이버 기본 문구)
- 칭찬만 크게: "최고예요", "대박", "정말 유익한" 남발
- 이모지 여러 개, ㅎㅎ·ㅋㅋ 남발(10개 중 1개 정도만 :) 또는 ~)
- 링크, 내 블로그 홍보, "제 글도 봐 주세요"
- 글에 없는 걸 아는 척하기, 안 해 본 경험을 한 척하기
- 투자 조언·의견 편들기("지금 사야죠", "정부가 잘못했네요")

## 이럴 땐 빼기 (skipped에 이유 한마디)

- 광고·홍보만 하는 블로그, 대출·리딩방·코인 홍보 글
- 슬픈 일(부고, 투병)만 쓴 글 — 서이추 메시지로 가볍게 말 걸기 어색함
- 본문이 거의 없어 짚을 게 없는 글
