## 신청 방식

- 이웃 그룹(계정마다): 지솜 **새 그룹**(지솜 계정 그룹은 이것 하나뿐, 2026-11-19 확인) / 모멍찌 **기타**. plan.json의 `group`에 이 값을 넣는다. 사용자가 '서이추' 같은 그룹을 만들면 그 이름으로 바꾼다. 이름이 맞는 그룹이 없으면 엔진이 맨 아래 그룹을 쓴다.
- 모드: **확인** (처음엔 메시지 표를 보여 주고 "신청해줘" 하면 신청. 사용자가 "이제 바로 해도 돼"라고 하면 '바로'로 바꾼다)
- 기본 인원: **30명** (네이버 서로이웃 신청은 하루 100명까지)
- 검색 정렬: **최신순** (최근에 글 쓴 사람이 활동 중이라 수락률이 높다. 사용자가 원하면 관련도순 `--order sim`)
- 업체·홍보 블로그: **건너뛴다** (`--keep-biz`로 포함)
- 신청 사이 간격: **8~15초 무작위** (바꾸면 make_apply_scripts.py의 gapMin·gapMax 기본값도 같이 고친다)
