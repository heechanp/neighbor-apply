# neighbor-apply

네이버 블로그 서로이웃 신청 스킬. 주제로 글을 검색해 사람마다 글 내용과 닉네임을 넣은 신청 메시지를 쓰고, PC의 Aside가 신청해요. 계정은 지솜(경제)·모멍찌(맛집) 중 골라요. 스킬 본체는 `neighbor-apply/` 폴더예요.

## PC에 연결하기

`python C:/Users/gmlck/claude/skill-tools/link_skill.py neighbor-apply`

## 업데이트 규칙

- 메시지 쓰는 법은 `neighbor-apply/references/message.md`.
- 계정, 그룹, 모드, 인원, 간격은 `neighbor-apply/references/settings.md`.
- `SKILL.md`는 동작 순서가 바뀔 때만 고쳐요.
- `.skill` 묶음 파일과 `서이추작업/` 결과는 올리지 않아요.
